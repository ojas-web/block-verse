Configure where database.* / cloud.* calls in scripts actually go
Add 1–6 of your own Firebase Realtime Database projects. Writes rotate through them round-robin; if one errors out (quota, permissions, offline), it automatically fails over to the next in the pool. Reads check every slot in the pool for the path.
Without a connector script below, calls default to a plain REST mapping: set → PUT {baseURL}/{path}, get → GET {baseURL}/{path}, onValue → polls GET every 3s. This is how you'd bridge to SQL/Postgres/etc. — point it at your own API in front of that database (browsers can't connect to SQL databases directly).
